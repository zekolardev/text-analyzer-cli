# Text Analyzer CLI

A lightweight Python command-line tool for analyzing text and extracting useful statistics.

## Features

- Character counting
- Word counting
- Line counting
- Sentence counting
- Longest word detection
- Input validation
- Empty input handling

## Requirements

- Python 3.10+
- No external dependencies
